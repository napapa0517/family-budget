# 우리집 가계부 웹앱 설치 방법

처음 한 번만 하면 됩니다. 컴퓨터에서 해주세요. 10분 정도 걸립니다.

## 1. 앱스 스크립트 편집기 열기

1. 구글 시트 "우리집 통합 가계부"를 엽니다.
2. 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 탭이 열립니다.
3. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 **우리집 가계부**로 바꿉니다.

## 2. 코드 붙여넣기

1. 왼쪽 파일 목록에서 **Code.gs**를 누릅니다.
   - 안에 있는 `function myFunction() {}`을 모두 지웁니다.
   - 이 폴더의 `Code.gs` 내용을 전부 복사해서 붙여넣습니다.
2. 파일 목록 위의 **＋ → HTML**을 누르고, 이름을 **Index**로 입력합니다. `.html`은 자동으로 붙으니 직접 쓰지 마세요.
   - 안에 있는 내용을 모두 지웁니다.
   - 이 폴더의 `Index.html` 내용을 전부 복사해서 붙여넣습니다.
3. **저장** 버튼(💾)을 누릅니다. 단축키는 Ctrl+S입니다.

## 3. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. "유형 선택" 옆 톱니바퀴를 눌러 **웹 앱**을 고릅니다.
3. 아래처럼 설정합니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | 요약 화면 |
   | 다음 사용자 인증 정보로 실행 | **웹 앱에 액세스하는 사용자** |
   | 액세스 권한이 있는 사용자 | **Google 계정이 있는 모든 사용자** |

   > 이렇게 설정하면 **시트를 공유받은 사람만** 데이터를 볼 수 있습니다. 링크가 새어 나가더라도, 시트 권한이 없는 사람에게는 데이터가 보이지 않습니다.

4. **배포**를 누릅니다.
5. "액세스 승인"이 나오면 본인 구글 계정을 고릅니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → 우리집 가계부(으)로 이동(안전하지 않음)**을 누릅니다. 직접 만든 앱이라 나오는 경고입니다.
   - 권한 목록을 보고 **허용**을 누릅니다.
6. 마지막 화면의 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 4. 열어보기

- 복사한 주소를 브라우저에 붙여넣으면 요약 화면이 나옵니다. 처음에는 가장 최근 달이 보입니다.
- **휴대폰에서:** 같은 주소를 카톡 '나와의 채팅' 등으로 보내서 엽니다. 그다음 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 5. 배우자에게 공유하기 (5단계에서 해도 됩니다)

1. 구글 시트 오른쪽 위 **공유**를 누릅니다.
2. 배우자의 구글 계정을 **편집자**로 추가합니다.
3. 웹 앱 주소를 배우자에게 보냅니다. 배우자도 처음 열 때 4번처럼 권한 승인을 한 번 거칩니다.

## 카카오페이 엑셀 올리는 법

1. 카카오페이 앱에서 내역을 엑셀로 받습니다. 메일로 옵니다.
2. 메일의 첨부 엑셀을 컴퓨터에 내려받아 엑셀로 엽니다. 비밀번호는 생년월일 6자리입니다.
3. **파일 → 정보 → 통합 문서 보호 → 암호 설정**에서 암호 칸을 비우고 **확인**을 누른 뒤 저장합니다.
4. 웹 앱의 **거래 내역 → ＋ 카카오페이 엑셀 올리기**를 누릅니다.
5. 누구의 엑셀인지(도리/효은) 고르고, 파일을 고릅니다. 여러 개를 한 번에 골라도 됩니다.
6. **올리기**를 누르면 새 거래만 추가됩니다. 이미 있는 거래는 건너뜁니다.

## 코드를 고친 뒤 다시 배포할 때 (주소 유지)

1. `Code_복사용.txt` 내용을 전부 복사해서 앱스 스크립트의 **Code.gs**에 덮어씁니다 (Ctrl+A → Ctrl+V).
2. `Index_복사용.txt` 내용을 전부 복사해서 **Index.html**에 덮어씁니다.
3. **Ctrl+S**로 저장합니다.
4. **배포 → 배포 관리**를 누릅니다.
5. 오른쪽 위 **✏️(연필)**을 누르고, **버전**에서 **새 버전**을 고른 뒤 **배포**를 누릅니다.
6. 새 기능이 시트를 고치는 권한을 쓰면, 처음 열 때 **권한 승인**이 한 번 더 나올 수 있습니다. 5단계와 같은 방법으로 허용하면 됩니다.

'새 배포'를 누르면 주소가 새로 생기니 주의하세요. 꼭 **배포 관리 → 연필 → 새 버전**으로 하세요.
